# TypeType-IOS cheat sheets

High-level, one page per subsystem. Start with `architecture.md`, then pick
the subsystem you are in.

| Sheet | What it answers |
|---|---|
| `architecture.md` | App states, DI, navigation, where things live |
| `player.md` | Tap → pixels: SABR/HLS, local HTTP server, PiP, queue |
| `theming.md` | Theme → pixels: roles, palette, repaint, settings layout |
| `data.md` | API client, auth/refresh, data quirks, playback endpoints |

Conventions (commits, CI, validation scope) live in `AGENTS.md`.
